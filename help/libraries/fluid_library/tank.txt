Tank


The Tank block represents A container for fluid or bulk matter with infinite capacity, an input at the top, and an output at the bottom. Optionally, Tank can contain some initial fluid (infinite amount of initial fluid is also possible). When the tank is not full, its content is always located at the bottom, and is filled from top. A non-full tank can accept input flow at any rate. When the tank is full, its input rate is restricted by the output rate (but not vice versa). When the tank is empty, its output rate is limited to the input rate.

The specified rate cannot be lower than the value of Utils.RATE_TOLERANCE constant, that is, 1.0e-9. If rate value falls below this value after recalculation, it will be snapped to 0.

The Fluid Library will try to maximize the out flow of all fluid sources; therefore, the priority of Tank out flow is set to 1 by default. Sometimes, to resolve flow priority conflicts, you may need to customize the out flow priority by further increasing it.

Tank can also serve as a source of fluid or as a disposal container with infinite capacity.

Although in the real tank different fluids can get mixed, the Tank block preserves the order of the incoming batches and transfers them to the output in the FIFO order (first in, first out). The output batch can be chosen to be the same as the original input batch, set to the default batch, or to a custom batch. You can also customize the batch initially contained in the tank, if there is any.

The Tank block allows you to define actions executed in the event of tank becoming full, empty, or the amount falling below or raising above the specified level. In addition, you can react to a new batch appearing the input or at the output.

Properties
Capacity
The maximum amount the tank can contain. This value cannot be less than the value of Utils.TOLERANCE. Infinite capacity can be set by typing infinity in the edit box of the property. more
Initial amount
The amount initially contained in the tank. This value cannot be less than the value of Utils.TOLERANCE. Infinite initial amount can be set by typing infinity in the edit box of the property. more
Limited output rate
If the option is selected (the value is equal to true), you can specify a custom upper limit of the rate the tank outflow rate. more
Maximum output rate
[Visible and applies if the Limited output rate option is set]
Custom upper limit of the tank outflow rate. The default value is 10 cubic meters per second. more
Custom priority
If the option is set (the value equals true), the priority of the tank outflow will be set to Output flow priority, otherwise it equals 1. The priority affects the LP solver when it tries to maximize the flow through the system. more
Output flow priority
[Visible and applies if the Custom priority option is set]
The custom priority of the tank outflow in the overall flowchart. Must be a positive integer. more
Custom initial batch

Actions
On full
The action executed when the tank gets full. If the tank is initially full, the action is not executed at the start of simulation.
On empty
The action executed when the tank becomes empty. If the tank is initially empty, the action is not executed at the start of simulation.
Action on above
If the option is set (the value equals true), you can specify the action executed when the amount of fluid in the tank goes up and reaches a particular threshold. more
Amount
[Visible and applies if the Action on above option is set]
The threshold for the On above action. This value cannot be less than the value of Utils.TOLERANCE. If the difference between the threshold value and the value of the Capacity property is less than Utils.TOLERANCE, an error will occur. more
On above
[Visible and applies if the Action on above option is set]
The action executed when the amount of fluid in the tank increases and reaches the threshold specified in the Amount property right above. The action is not executed when the amount is initially above or at the threshold, or if the threshold is crossed while the amount is decreasing. more
Action on below
If the option is set (the value equals true), you can specify the action executed when the amount of fluid in the tank decreases and reaches a particular threshold. more
Amount
[Visible and applies if the Action on below option is set]
The threshold for the On below action. This value cannot be less than the value of Utils.TOLERANCE. If the difference between the threshold value and 0 is less than Utils.TOLERANCE, an error will occur. more
On below
[Visible and applies if the Action on below option is set]
The action executed when the amount of fluid in the tank decreases and reaches the threshold specified in the Amount property right above. The action is not executed when the amount is initially below or at the threshold, or if the threshold is crossed while the amount is increasing. more
On new batch at input
The action executed when a new batch appears at the tank input. It will not necessarily start flowing into the block. more
On new batch at output
The action executed when a new batch reaches the tank output, even if the output batch is set to default or custom. more
On rate change
The action executed when any of the flow rates (input or output) changes.
Changing something in the action may result in another immediate rate change and immediately following another call of On rate change, so the user can possibly create a livelock.
