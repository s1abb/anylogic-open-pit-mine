FluidDispose


The FluidDispose block accepts the incoming flow and disposes it (removes from the system).

It is a typical ending block of a Fluid Library flowchart. Accepts flow at any rate.

You can connect no more than one block to the input port of the FluidDispose block (unlike PedSink and so on).

On rate change
The action executed when the flow rate changes.
Changing something in the action may result in another immediate rate change and immediately following another call of On rate change, so the user can possibly create a livelock.
